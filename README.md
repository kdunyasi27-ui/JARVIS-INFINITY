# JARVIS INFINITY

Kişisel yapay zekâ asistanı.

## Özellikler

- Kullanıcı kayıt ve giriş sistemi
- Kişiye özel sohbet geçmişi
- Yapay zekâ uzman ajanları
- Kalıcı kullanıcı hafızası
- Birden fazla model sağlayıcısı desteği
- Araştırma modülü altyapısı
- Günlük sistem değerlendirmesi
- Mobil uyumlu arayüz
- PWA desteği
