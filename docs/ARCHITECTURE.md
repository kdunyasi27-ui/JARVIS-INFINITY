# JARVIS INFINITY - Sistem Mimarisi

## 1. Proje amacı

JARVIS INFINITY; farklı yapay zekâ modellerini,
uzman ajanları, hafızayı ve otomasyonları tek
bir platformda birleştirmeyi hedefler.

## 2. Ana bileşenler

- API: FastAPI
- Arayüz: HTML, CSS ve JavaScript
- Veritabanı: SQLite
- Model bağlantısı: OpenAI uyumlu API
- Uzman ajanlar: Araştırma, yazılım, analiz,
  yazarlık, planlama, eğitim ve yaratıcılık
- Dağıtım: Docker

## 3. Veri akışı

1. Kullanıcı mesaj gönderir.
2. API kimlik doğrulamasını kontrol eder.
3. Uzman ajan seçilir.
4. Konuşma geçmişi yüklenir.
5. Yapay zekâ sağlayıcısına istek gönderilir.
6. Yanıt veritabanına kaydedilir.
7. Yanıt kullanıcıya iletilir.

## 4. Güvenlik

- API anahtarları gizli tutulur.
- Yetkisiz istekler reddedilir.
- Önemli işlemler kullanıcı onayı gerektirir.
- Otomatik kod değişiklikleri test edilmeden
  ana sisteme uygulanmaz.

## 5. Geliştirme hedefleri

- Çoklu model desteği
- Uzman ajan koordinasyonu
- Kalıcı hafıza
- Sesli asistan
- Görüntü analizi
- Araştırma araçları
- Kontrollü otomasyon
- Android ve masaüstü desteği

## 6. Geliştirme ilkesi

Önce güvenli ve çalışan temel sistem kurulur.
Yeni özellikler ayrı ayrı test edilir.
Kritik değişiklikler kullanıcı onayı olmadan
yayına alınmaz.
